# Baseline regression tests

## Проблема

Перед переходом к UCM необходимо воспроизводимо зафиксировать поведение Java/SQL и известные ошибки legacy-индексатора.

## Цель и границы

Добавить автономные characterization tests для восьми случаев этапа 0. Production-код и контракты не меняются. Проверки PostgreSQL, миграций, COPY и полного CLI относятся к следующему change `integration-test-foundation`.

Известные ошибки проверяются как наблюдаемое поведение, а не как желаемый контракт. При исправлении соответствующей ошибки тест должен быть заменён проверкой целевой семантики в том же change.

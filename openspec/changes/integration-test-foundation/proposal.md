# Integration test foundation

## Проблема и цель

Unit tests не проверяют реальные транзакции PostgreSQL, COPY, миграции и запуск CLI. Добавляем опциональный интеграционный набор на PostgreSQL 15 для безопасной последующей миграции хранилища.

## Границы

Проверяем существующие legacy-таблицы и публичные команды без изменения production-кода. pgvector и поисковые проекции появятся со своими миграциями. Нагрузочные, recovery и конкурентные сценарии публикации относятся к последующим changes.

# UCM symbol model

## Проблема и цель

Имени метода недостаточно для различения перегрузок. Нужны типизированные декларации, области видимости, употребления и ссылки на типы, которые могут оставаться неразрешёнными.

## Границы

Добавляем Symbol, Scope, Occurrence, TypeRef и CallableSignature. Не меняем Java parser, storage и legacy identity. Извлечение, разрешение вызовов и проверка целостности batch относятся к последующим changes.

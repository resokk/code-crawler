# UCM external reference

## Проблема и цель

Индексация одного репозитория должна сохранять внешние зависимости независимо от наличия других индексов. Нужен контракт неразрешённой зависимости, пригодный для будущего query-time resolver.

## Границы

ExternalReference, минимальные типизированные selectors, локальные проверки, JSON Schema, Evidence/Coverage. Без поиска кандидатов, глобального linking, сетевых вызовов, resolver cache, миграций и изменения анализаторов. BPMN/API/schema adapters расширят selectors позднее.
